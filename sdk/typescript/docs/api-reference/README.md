# API Reference

## 语言

| 语言 | 包名 | 包管理器 |
|------|------|---------|
| TypeScript | `@agentprimordia/sdk` | npm |
| Go | `github.com/agentprimordia/ap` | go modules |
| Python | `agentprimordia` | pip |
| Java | `com.agentprimordia` | gradle/maven |
| Rust | `agentprimordia` | cargo |
