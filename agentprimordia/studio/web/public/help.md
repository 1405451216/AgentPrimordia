# AgentPrimordia Studio 帮助

## 面板

| 路由 | 面板 | 说明 |
|------|------|------|
| `/` | 概览 | 集群健康、知识蒸馏、近期实验一览 |

## 键盘快捷键

| 按键 | 作用 |
|------|------|
| `Shift + /` | 打开/关闭快捷键面板 |
| `/` | 聚焦当前页搜索框 |
| `g 1-5` | 跳转页面：1 概览 · 2 混沌 · 3 集群 · 4 学习 · 5 市场 |
| `Esc` | 关闭对话框或面板 |

## 混沌实验

混沌实验用于验证系统在故障注入下的稳态表现：

- 实验前系统应处于稳态基线（稳态前）
- 注入故障（延迟/错误/超时/网络分区/进程终止）
- 实验后检查系统是否回到稳态（稳态后）
- 假设验证 = 实验是否证明了你的预期

破坏性故障类型（网络分区、进程终止）会经过两步确认，请确认影响范围后再运行。
