# 并发原语

AgentPrimordia 的 `internal/concurrency` 包提供生产级并发原语，目前主要包含跨进程文件锁。

## FileLock

`FileLock` 基于操作系统文件锁实现，用于多进程之间的互斥访问。

### 使用场景

- 多个 AP 进程共享同一个 SQLite 数据库
- 防止并发写入配置文件
- 分布式任务调度中的本地互斥

### 快速开始

```go
lock := concurrency.NewFileLock("/var/run/my-agent.lock")

// 阻塞获取锁
if err := lock.Lock(); err != nil {
    panic(err)
}
defer lock.Unlock()

// 业务逻辑
```

### 非阻塞尝试

```go
if err := lock.TryLock(); err != nil {
    fmt.Println("锁已被占用")
    return
}
defer lock.Unlock()
```

### 带超时的锁

```go
ctx, cancel := context.WithTimeout(ctx, 5*time.Second)
defer cancel()

if err := lock.LockContext(ctx); err != nil {
    fmt.Println("获取锁超时")
    return
}
defer lock.Unlock()
```

## 内部使用

FileLock 被以下模块使用：

- `internal/memory/sqlite.go`：SQLite 存储初始化锁
- `internal/persist/sqlite_checkpoint.go`：检查点写入锁

## 注意事项

1. 文件锁是进程级互斥，不替代 goroutine 级锁
2. 锁文件路径应稳定且可写
3. 程序异常退出时，操作系统会自动释放文件锁
