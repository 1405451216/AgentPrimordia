# 多模态实时（Realtime）

Realtime 模块让交互从"文本流式对话"跃迁为"语音 / 视频 / 图像实时双向流交互"。对应 V4 路线图 v3.6。

## 核心模型

- **RealtimeHub**：双向流会话编排器，串联 ASR → 推理 → TTS，管理会话生命周期。
- **RealtimeSession**：单个实时会话的状态机载体。
- **ASRAdapter / TTSAdapter**：语音识别 / 合成可插拔接口，默认提供 `MockASR` / `MockTTS`。

## 会话状态机

`idle → listening → thinking → speaking → listening …`。`listening` 接收输入，`thinking` 推理中，`speaking` 输出中。

## 打断（Barge-in）

`BargeInHandler` 支持用户在 Agent 表达（`speaking`）中插入时立即响应，转回 `listening`；仅 `speaking` 状态可打断，其余状态返回错误。

## 感知与融合

- **AudioStream**：chunk 缓冲 + 静音检测（RMS 阈值）+ 音频格式协商（默认 16kHz/单声道/16bit PCM）。
- **VisionStream**：连续视频帧输入（非单张图片）。
- **Fusion**：文本 + 视觉 + 音频多路输入融合为 LLM 上下文（`FusedInput`）。

## 运行时装配

```go
rt := realtime.NewRuntime(realtime.RuntimeConfig{
    ASR: myASR, TTS: myTTS, React: myReactBridge, // 均可选
})
rt.Start(ctx)
defer rt.Stop()
rt.OpenSession("s1")
rt.PushAudio("s1", pcmBytes)
rt.PushVision("s1", jpegBytes, 1280, 720)
text, audio, _ := rt.ProcessTurn(ctx, "s1", "用户文本")
```

`Runtime` 为每会话装配感知流与事件总线，`CleanupManager` 在空闲超时后自动关闭会话并回收资源。

## 跨组件集成

实时 × 多模态（视觉帧分析）、× 边缘（浏览器/边缘 WebGPU 推理）、× 自治（目标进度语音汇报）、× 守卫（转写文本 PII/注入检测）、× A2A（agent-card 输入输出模式声明）。

## 能力注入与公共 API

- 链式注入：`agent.WithRealtime(ap.RealtimeConfig{Hub: hub})`，引擎经 `RealtimeCapable` 发现。
- 公共 API：`pkg/realtime.go` 导出 `RealtimeHub` / `RealtimeSession` / `ASRAdapter` / `TTSAdapter`。
- CLI：`ap realtime voice`（本地 mock 可跑的语音会话 + 打断演示）。
- 接入指南：`docs/guides/实时通信.md`。
