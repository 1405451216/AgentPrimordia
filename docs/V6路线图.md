# AgentPrimordia v6.0 路线图实施计划（v5.1 – v6.0）· 修订版

> **文档定位**：v5.0 平台里程碑收官（加权复测 ≈8.8/10）后，v5.1–v6.0 的核心能力深耕弧线。
>
> **修订说明（2026-08-19）**：初版十个版本被评审否决——运维/认证/生态等维护性主题稀释了弧线野心。本版重构：**每版本只挂一个核心优化任务，全部聚焦核心能力的大蜕变**；小改动合并进对应版本或降级为持续维护项（不占版本号）。
>
> **二次修订（2026-08-21）**：评审补充六项——① v5.1 CI secrets 升为 P0 前置任务并设计无 key 降级路径；② v5.2 开工前强制重构风险评审；③ 模糊量化措辞补具体数字（阈值+样本量+显著性水平）；④ 每版加宽松时间盒；⑤ v5.5 拆分——对标矩阵降为随行项、组织智能独立为核心任务；⑥ 弧线中段（v5.3）设轻量外部校准点。
>
> **弧线主题**：**优化 → 进化 → 学习 → 借鉴 → 大成**
> 从「功能齐全的通用框架」到「持续进化的认知 Agent 内核」。
>
> **版本基线**：Go SDK v5.0.0 / TypeScript SDK v5.0.0　**创建/修订日期**：2026 年 8 月 19 日

---

## 一、弧线铁律

| # | 铁律 | 说明 |
|---|------|------|
| 1 | **每版本一个核心优化任务** | 版本主题即核心任务，拒绝多主题拼盘；小改动只能作为「随行项」挂在核心任务下 |
| 2 | **大蜕变优先** | 每个版本必须包含至少一项架构级或范式级变化（内核重构/记忆架构/自进化闭环等），纯调参式改进不构成版本 |
| 3 | **核心能力聚焦** | 弧线只投核心五件套（引擎/记忆/工具/调度/学习）；DX/运维/安全/生态进入持续维护清单（§二） |
| 4 | **量化门槛** | 每版本核心任务必须带量化验收（成功率/召回/P95/成本至少其一），数字必须具体到阈值+样本量+显著性水平（如 N≥30 次、p<0.05），进回归门，不达标不 bump |
| 5 | **双语言同步** | 核心能力变更 Go/TS 对等落地并纳入 cross-language-spec |
| 6 | **TDD + 实证** | 先测试后实现；完成时附代码证据与数据（AGENTS.md §6.1 失败即停） |
| 7 | **向后兼容到 6.0** | 5.x 全部新增式演进，废弃标注 `Removed in`；仅 v6.0 主版本执行移除与契约重锁 |
| 8 | **时间盒** | 每版带宽松时间盒（±50% 浮动）；超时 1.5× 未达验收即触发范围裁剪评审，不允许无限期挂起 |
| 9 | **外部校准** | 弧线中段（v5.3）设一次轻量外部校准点，防止全程内向聚焦偏离真实使用场景 |

## 三、v5.1 优化（Optimize）——核心优化任务：核心链路质量革命

> **本质跃迁**：从「能力齐全」到「质量被度量且打满」——引擎/记忆/调度三大核心的每一项关键质量都有数字、有门禁、有基线，为后续进化提供标尺。
> **立项证据**：TS HNSW `search()` 召回实测 ≈0.7（BFS 候选上限瓶颈）；复测残余风险 #1（真实跑分依赖 nightly）；核心链路质量散点优化从未系统化。

### 核心任务（四件）

| # | 任务 | 量化验收 |
|---|------|---------|
| 1 | **质量度量体系**：核心四件套指标（召回率/任务成功率/P95/成本）全部进回归门 + 质量看板；nightly 真实 LLM 跑分例行化（关闭 v5.0 残余风险 #1） | 看板上线；nightly 连续 7 天真实产出；漂移告警可用 |
| 2 | **检索质量革命**：TS HNSW `search()` 重写为真实 ef-search（对齐 Go beam search 语义）；双线召回基准套件入 cross-language-spec；RAG Hit@k/MRR 基线建立 | 双线 recall@10 ≥ 0.95（300/1000/3000 三档固定种子集）且双线差值 ≤0.02 |
| 3 | **引擎热路径**：ReAct 主循环延迟与 token 开销优化（上下文压缩 Go 对齐 TS TokenBudget） | 关键路径 P95 较 2026-Q4 基线降 ≥20%；同任务集 token 成本降幅可量化 |
| 4 | **调度质量**：Pool 尾延迟治理 + 预算超限自动暂停/恢复策略 | 尾延迟 P99 基线入库；预算护栏回归测试全绿 |

**P0 前置任务（开工第一周必须完成，不占核心任务位）**：

| # | 任务 | 说明 |
|---|------|------|
| 1 | CI secrets 就位 | 向 CI 提供 LLM API Key secrets（nightly 真实跑分依赖）；逾期未就位则启用任务 2 降级路径 |
| 2 | 无 key 降级路径 | 本地 recorded-response 回放基准：录制真实 LLM 响应集，CI 无 key 时回放跑分，保证质量门不断线 |

**随行小改动**：排行榜发布自动化、Soak 报告例行化、评估数据集扩容（≥150 条）。

**验收场景**：一份《v5.1 质量基线报告》——召回/成功率/P95/成本四件套数字 + nightly 看板实况。

**时间盒**：预期 3-4 周。

## 四、v5.2 进化·壹（Evolve I）——核心优化任务：认知引擎架构进化

> **本质跃迁**：从「单一 ReAct 循环」到「策略驱动的认知内核」——推理策略成为引擎的一等公民，引擎深度可配置、可验证、可自适应。
> **立项证据**：react_loop 单策略架构贯穿 v0.1–v5.0；plan 级 checkpoint 自 v3.4 起一直是缺口（checkpoint 只存轮次不存计划）；引擎可信度分项 9.0 的下一程是「引擎更聪明」而非「引擎更像现在」。

### 核心任务（四件）

| # | 任务 | 量化验收 |
|---|------|---------|
| 1 | **统一引擎内核**：Strategy 抽象落地——ReAct / Plan-Execute-Reflect / 验证循环（生成→检验→修正）策略可插拔热切换，react_loop 重构为「内核 + 策略插件」 | 三策略可运行时切换；A/B 对照 harness 可复现；双线对齐 |
| 2 | **验证循环原生化**：verifier 为引擎一等公民（可配置：自校验/工具校验/测试校验），失败自动进入修正轮 | 验证循环开关对照实验：任务成功率差值报告 |
| 3 | **自适应思考深度**：test-time compute 预算——难题深想、易题浅想，深度由任务信号驱动 | 同任务集：成功率不降且成本下降（或成功率上升，Pareto 报告） |
| 4 | **计划级 checkpoint**：规划树持久化 + 断点续跑到计划级（偿还 v3.4 缺口） | 计划中途 kill 后 Resume 从断点子任务继续，回归测试全绿 |

**前置任务（开工前强制，不通过不得动内核）**：重构风险评审——输出①策略接口冻结点清单、②feature-flag 回滚开关方案（新旧内核可运行时切换回退）、③react_loop 回归测试清单；评审记录归档随代码证据提交。

**验收场景**：同一基准套件三策略 A/B 跑分（N≥30 次重复），任务成功率较 v5.1 基线提升 ≥5%（双侧配对检验 p<0.05），且 token 成本不升。

**时间盒**：预期 4-6 周。

## 五、v5.3 进化·贰（Evolve II）——核心优化任务：记忆认知化

> **本质跃迁**：从「检索仓库」到「认知记忆」——记忆不再是存取，而是会沉淀、会组织、会遗忘、会迁移的经验系统，并承载 Agent 的自我模型。
> **立项证据**：三层记忆（FTS5+HNSW+RAG）是框架核心卖点但只有检索能力；v3.4 记忆回读已接线却无收益度量；压缩/蒸馏（KnowledgeDistiller）与记忆系统割裂。

### 核心任务（四件）

| # | 任务 | 量化验收 |
|---|------|---------|
| 1 | **记忆固化管道**：episodic → semantic 固化（LLM 蒸馏沉淀 + 重要性衰减 + 主动遗忘），存储占用与检索质量双向度量 | 固化前后：存储占用降幅 + recall 保持率报告 |
| 2 | **图-向量混合检索**：实体-关系知识图与 HNSW/FTS 统一路由（按查询类型分流/融合） | Hit@k 较 v5.1 纯向量基线相对提升 ≥10%（300/1000/3000 固定种子集，消融对照） |
| 3 | **记忆迁移**：跨任务/跨会话经验复用（相似任务自动注入历史经验） | 对照组实验：相似任务推理轮数/成功率改善幅度 |
| 4 | **自我模型记忆**：Agent 能力画像与失败画像结构化沉淀（供 v5.4 学习回路消费） | 画像条目可查询、可注入系统提示，回归测试覆盖 |

**验收场景**：记忆消融对照实验——同一任务集「开记忆 vs 关记忆」成功率差值报告 + 固化管道演示。

**外部校准点（铁律 9）**：本版本内邀请 ≥3 个真实使用方走查 quickstart 并完成一个真实场景接入试点，反馈作为 v5.4/v5.5 立项输入。

**时间盒**：预期 4-6 周。

## 六、v5.4 学习（Learn）——核心优化任务：自进化闭环

> **本质跃迁**：从「人调 Agent」到「Agent 从结果中改进自己」——结果反馈驱动的自我改进成为框架核心能力，且带安全边界。
> **立项证据**：v3.6 已证方向（自愈 replan、tool_learning 回注、自举成功率 0.333→0.667→1.0），但均为散点机制，未成闭环；skills 习得（v4.4）与失败模式记录（v4.1 FailureStore）已就绪待串联。

### 核心任务（四件）

| # | 任务 | 量化验收 |
|---|------|---------|
| 1 | **结果反馈回路**：任务结果 → 失败模式库 → prompt/参数/工具配置自动改进建议（人工确认后生效） | 闭环端到端演示；建议采纳率与改进幅度报告 |
| 2 | **技能合成**：成功轨迹自动合成为可复用技能（带验证与签名），与技能市场打通「习得→发布→复用」 | Agent A 合成技能 → 市场发布 → Agent B 安装使用成功，全链路可追溯 |
| 3 | **自举规模化**：AP 参与 AP 日常开发（基准跑分/缺陷分诊/文档），季度改进曲线制度 | 季度报告：成功率/缺陷检出率曲线持续上升（对照 base 模型） |
| 4 | **自改进安全边界**：自我改进沙箱——改进范围限定配置/prompt/技能层，代码层变更强制人工审核；改进前后全量回归不可退化 | 沙箱越界尝试被拦截的对抗测试；回归零退化证明 |

**验收场景**：一场受控自进化实验——同一任务集经 ≥5 轮进化迭代（每轮 ≥20 任务），成功率曲线上升且无回归（任一轮较基线退化 >2% 即判失败），全程审计可查。

**时间盒**：预期 4-6 周。

## 七、v5.5 借鉴（Learn from the Frontier）——核心优化任务：组织智能

> **本质跃迁**：多 Agent 从协作升级为组织；前沿借鉴以制度化随行方式持续吸收，不再独占核心任务位。
> **立项证据**：v3.8 Swarm 已证「规模×N 成功率不降」，组织化是其自然下一程；v5.3 自我模型记忆 + v5.4 技能合成为组织分工提供了消费素材。
> **拆分说明（2026-08-21 二次修订）**：原「SOTA 对标」与「组织智能」双主题违反铁律 1——对标矩阵与前沿复现管道降为随行项/持续维护（§二），组织智能独立为核心任务。

### 核心任务（两件）

| # | 任务 | 量化验收 |
|---|------|---------|
| 1 | **组织智能**：多 Agent 组织化——共享记忆黑板 + 涌现分工 + 组织级调度，规模化不降质 | 组织规模扩展基准：N 翻倍成功率下降 ≤2%（延续 v3.8 口径，每组 N≥20 次重复） |
| 2 | **旗舰级端到端验证**：一个复杂端到端任务（Agent 团队自主完成中型功能开发：规划→编码→测试→提交）验证优化/进化/学习三阶成果 | 端到端演示 + 过程审计 + 成功率统计（N≥10 次重复，成功率 ≥70%） |

**随行小改动**：能力对标矩阵 v1（与前沿 Agent 范式逐项对账，输出持平/落后/领先三态矩阵，落后项转立项候选）；前沿复现管道试运转（本版本内复现 ≥1 项前沿机制并纳入基准套件）。

**验收场景**：一场 Agent 团队自主开发的完整实况（含失败与自恢复过程）+ 组织规模扩展基准报告。

**时间盒**：预期 4-6 周。

## 八、v6.0 大成（Culminate）——核心优化任务：认知内核定型与契约重锁

> **本质跃迁**：框架身份升级——从「通用 Go Agent 框架（ReAct 核心）」到「会进化的认知 Agent 内核」；主版本破坏性清理 + 稳定性承诺升级。

### 核心任务（四件）

| # | 任务 | 量化验收 |
|---|------|---------|
| 1 | **核心能力转正**：v5.x 新引擎/记忆/学习 API 经 stability 双门审查，Experimental → Stable | stability_compliance + api-contract 双门全绿 |
| 2 | **破坏性清理**：按 VERSIONING 处理全部超期废弃（在册 `Option` 别名复审提前与否；5.x 新增废弃全部出清） | deprecation_residual 门 0 残留 |
| 3 | **契约重锁**：v6 契约基线冻结 + 迁移指南（仿 v5-deprecations.md 体例） | 旧代码按指南迁移后全绿 |
| 4 | **深度复测**：加权总评冲 ≥9.0，核心分项（引擎/评估/性能）≥9.0 | 复测报告发布，四项残余风险全部关闭 |

**验收场景**：v6.0.0 发布 + 复测 ≥9.0 + 一次完整的迁移演练实况。

**时间盒**：预期 3-4 周。
