## ③ 主指标（二值化口径与判定器）

- **指标**：任务成功率（二值）。
- **二值化口径**：题面 grading.success 断言全部通过 = 1，否则 = 0；grading.partial 过程分不参与成功判定（docs/evals/README.md「判定口径」节）。
- **判定器**：internal/eval/asserts.go 的 EvaluateAll（asserts.go:308）在沙箱终态执行七种确定性断言——file_exists / file_contains / file_eq / json_path_eq / lines_match_count / tool_registered / tool_output_json_eq（断言常量 asserts.go:33-39）。
- **确定性保证**：文件不存在判 false（不误计为判定异常）、沙箱越界与未知断言种类直接报错（asserts.go:13-17）；判定不依赖 LLM——judge 仅用于开放式输出质量标定，**禁止 LLM judge 做主指标**（asserts.go:9-11）。
- **检验**：双臂同题配对 → McNemar 精确二项检验（α=0.05 双侧；拒绝域由 internal/eval/stats.go 的 McNemarPower 精确枚举；统计框架锚点 commit 5d88dabd，TS 镜像 ab1e23e2）。

## ⑤ 效应量与功效计算

- **效应量假设**：+15pp（S0-2 基线摸底起测点 + 保守增量，模板预登记）。
- **功效计算入口**：internal/eval/stats.go 的 SampleSizeMcNemar（stats.go:281，精确枚举 + 二分找最小达标 n）。
- **采用输出值**：SampleSizeMcNemar(delta=0.15, omega=0.30, alpha=0.05, targetPower=0.80) = **108 题/臂**（功效速查表「配对 McNemar·不一致率 30%·+15pp」行锁定参考值，测试锁定；≥60/臂 仅为地板，不是判据）。
- **四格期望**：仅处理臂成功 p10=(ω+δ)/2=0.225；仅基线臂成功 p01=(ω−δ)/2=0.075；不一致率 ω=0.30。
- **证伪声明**：旧稿手估样本量已被 S0-1 精确功效计算证伪（该手估 n 下实测功效仅 0.581，达不到 0.80；详见速查表 R2 自纠记录）——验收样本量一律以 SampleSizeMcNemar 输出为准，禁止手估。
- **功效速查表引用行**（模板 §功效速查表，全部为 SampleSizeMcNemar / SampleSizeTwoProportion 精确枚举 + 参考值测试锁定的精确值）：

  | 设计                         | 效应量     | 每组 n                |
  | ---                          | ---        | ---                   |
  | 独立两比例（p0=0.5）         | +15pp      | 170                   |
  | 独立两比例（p0=0.5）         | +20pp      | 93                    |
  | 独立两比例（p0=0.5）         | +30pp      | 39                    |
  | 配对 McNemar（不一致率 30%） | +15pp 观测 | **108（本实验采用）** |
  | 配对 McNemar（不一致率 30%） | +20pp 观测 | 59                    |
  | 配对 McNemar（不一致率 40%） | +20pp 观测 | 80                    |
  | 配对 McNemar（不一致率 40%） | +30pp 观测 | 34                    |

- **多重比较**：双臂单主指标，无校正；次指标仅描述性，不做门槛（模板预登记）。
- **整集重复采样协议**（长程留出仅 9 题 < 108）：
  1. 采样单元 =（题面 × 重复轮次），题面池 = 整集 24 题（9 留出 + 15 可见，均为冻结题面）；
  2. 第 1–4 轮整集全跑 = 96 配对单元；第 5 轮按 seed=20260831+5 的确定性排列取前 12 题 = 12 单元；合计 108 配对单元 = 216 次运行（108×2 臂，与路线图命题 1 预算一致）；
  3. 每个重复实例 = 独立沙箱 + 独立运行 seed，采样协议与首轮完全一致（模板计划书模板第 17 行预登记）；
  4. 留出对账：holdout:true 的 9 题在各轮成绩全量单列（占比预计 ≈37.5% 与整集留出率一致，由第 5 轮排列决定），R4「验收只认留出」以逐轮全披露方式落实，不挑轮次、不重算。

| 异常处理  | 网络/限流类异常允许登记后补跑，补跑记录全量披露；判定异常不计成功                          |

## ⑦ 成本估算

- **token 量级**：216 次长程运行 × 平均 180 calls × 1.2k tok/call ≈ 4.7×10⁷ token（模板成本公式，旗舰价目口径）。
- **预算级别**：里程碑级（计划书注册的功效 n=108 为唯一合法验收口径；探索级 ≤20 题 × 1 采样不可用于验收，开发期调参如需小样本另行走探索级并声明）。
- **预算通道**：V7 路线图 §九 B4 评测 token 预算；金额按申请时点旗舰价目填列并对照告警线，超支触发铁律 8 裁剪评审，禁止静默缩水样本。

## ⑨ 判定口径（R3）

- **达成门（唯一）**：McNemar 精确检验 p<0.05 且配对差值点估计 ≥ +15pp。
- **报告口径（R3 成对披露）**：
  - 双臂各自成功率：点估计 + Wilson 95% 区间（internal/eval/stats.go WilsonInterval，stats.go:65），禁裸百分比宣称；
  - 差值：配对差值点估计 + 95% 区间；不一致四格表（n10/n01）全量披露；
  - 整集口径与留出子集口径同时报告，禁止以任一子集重算替代全量口径。
- **报告物清单**：原始运行台账（题 id、轮次、臂、seed 四元组）+ 不一致四格表（n10/n01）+ 24 题逐题双臂方向表 + 留出子集单列表，随报告归档可复核。
- **未达成处置**：命题 1 记未达标 → 按 ⑧ 登记降级豁免；工程地板（状态图内核 + 预演 gate + 回溯差异进失败库 + state-checkpoint 协议）照常交付（路线图 §三工程地板条款）；v7.0 翻默认按提案 §2.3 与版本规范登记表处理——数字不达标不翻，撤销或延迟登记。
