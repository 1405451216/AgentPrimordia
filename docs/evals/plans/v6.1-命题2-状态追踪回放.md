## ③ 主指标（二值化口径与判定器）

- **指标**：回放断言准确率（二值）。
- **分析单元**：断言实例 = 一条断言（里程碑断言 / grading.success / grading.partial）在一个回放点上的一次判定。
- **二值化口径**：状态图断言结论与金标一致 = 1，不一致 = 0。
- **回放点定义**：里程碑断言在其里程碑达成点判定，终局断言在轨迹终点判定——回放点集合按题面 milestones 顺序 + 终点预登记。
- **金标判定器**：internal/eval/asserts.go 的 EvaluateAssertion（asserts.go:166）在该回放点沙箱快照上执行七种确定性断言（asserts.go:33-39：file_exists / file_contains / file_eq / json_path_eq / lines_match_count / tool_registered / tool_output_json_eq）；文件不存在判 false、越界与未知种类报错（asserts.go:13-17）。
- **人工核定**：100 条断言实例逐条由标注者按沙箱终态 + 轨迹日志核定；人工否决机器判定时以人工为准并登记判定器缺陷——缺陷走根因修复 + 全量重标，不得就地改判。
- **禁 LLM judge**：机器判定全部走 asserts.go 确定性断言；人工标注仅作金标核定与分歧复核，不引入 LLM judge 主指标（asserts.go:9-11）。

## ⑤ 样本量与精度（无 SampleSizeMcNemar 适用性的声明）

- **不适用声明**：本命题为单臂质量标定，无双臂成功率主门，不调用 SampleSizeMcNemar；功效速查表的 McNemar 行仅适用于命题 1（R2 功效门针对 A/B 配对验收）。
- **样本量来源**：n=100 由路线图命题 2 预登记（100 条回放人工标注）；本计划书注册其构成与截取协议（见 ⑥）——验收只认注册口径。
- **Wilson 门的 n=100 实现路径**（internal/eval/stats.go WilsonInterval，stats.go:65）：
  - x=90：点估计 90.0%，Wilson 95% 区间 [82.6%, 94.5%]——下界 ≥82% ✓；
  - x=89：下界 81.7%——<82% ✗；
  - 等价式：**失败 ≤10 条**（两判据在 n=100 下同时成立的最宽失败数）。
- **抽样波动声明**：n=100 下点估计标准误 ≈2.7pp（p=0.92 时）——Wilson 下界门已内建该波动，不做额外校正。
- **扩样纪律**：实测失败 11–15 条即未达标；不得以扩样（n>100）重算救门——扩样属样本构成协议变更，须维护者书面批准并登记后按新协议全量重标。
- **多重比较**：单主指标，无校正；次指标仅描述性，不做门槛。

## ⑦ 成本估算

- **token 量级**：轨迹采集 24 × 180 calls × 1.2k tok/call ≈ 5.2×10⁶ token；第 2 轮补样 ≤24 题 ≤5.2×10⁶ token；回放与对账为本地确定性计算，零 LLM token。合计 ≤1.0×10⁷ token。
- **人工成本**：100 条标注工时（非 token 成本）随报告披露。
- **预算级别**：里程碑级（n=100 为本计划书注册的验收口径；探索级 ≤20 题 × 1 采样不可用于验收）。
- **预算通道**：V7 路线图 §九 B4；金额按申请时点旗舰价目填列并对照告警线，超支触发铁律 8 裁剪评审，禁止静默缩水样本。

## ⑨ 判定口径（R3）

- **达成门**：断言准确率点估计 ≥90% 且 Wilson 95% 下界 ≥82%（成对报告，二者同验；n=100 等价式：失败 ≤10 条）。
- **报告写法（R3 成对披露）**：「x/100，Wilson 95% 区间 [下界, 上界]」。预登记参考值示例：90/100 → [82.6%, 94.5%]；92/100 → [85.0%, 95.9%]；**若 100/100 → 「100/100，Wilson 95% 区间 [96.3%, 100%]」——禁裸 100% 宣称**（本命题是抽样比率指标，不属确定性例外）。
- **子集纪律**：整集实例口径与留出题实例口径同时报告，禁止以任一子集重算替代全量口径。
- **报告物清单**：100 条标注原始记录（含依据片段与复核结论）+ 分歧样本双人复核记录 + 标注指南 + 运行四元组台账，随报告归档可复核。
- **可复核性**：金标判定器为确定性断言，第三方可按冻结题面（027b5c56）独立复跑机器侧结论对账。
- **未达成处置**：不放宽门、不换样本；不一致实例全量披露 + 根因修复复审后按原协议重跑全集；未达标即按 ⑧ 登记降级豁免，工程地板（断言一致性门入 CI + 回溯差异进失败库）照常交付。
