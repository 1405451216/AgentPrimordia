## 命题 1：缺口场景自主生成增益 +≥20pp

### ① 假设

- H1：AutoLoop 闭环（缺口登记→生成→彩排→对抗→签名注册→复用）使缺口场景任务成功率提升 ≥20pp。
- H0：提升 < 20pp 或生成工具未通过信任链/沙箱断言。

### ② 双臂定义

- A（基线）：无自主生成——缺口工具缺席，agent 以既有工具尽力完成；
- B（处理）：AutoLoop 全闭环后的同题重跑。
- 配对原则：同题、同模型档、同预算、同沙箱；两臂唯一差异 = 缺口工具是否经闭环注册。
- 题面：缺口集 ≥50 题由 GapAuditor 对真实轨失败库确定性聚合产出（missing_tool/repeated_failure 双信号），R4 冻结注册（sha256 入 manifest 台账）。

### ③ 效应量与功效计算

- 配对 McNemar，δ=+0.20，ω=0.30，α=0.05，power=0.80 → **SampleSizeMcNemar = 59 题/臂**（2026-09-02 以仓内锁定工具精确枚举，internal/eval/stats.go——禁止手估）。
- ≥50 题缺口集若不足 59，扩充至功效达标（缺口语义下限 59）。

### ④ 分析计划

- 主指标：缺口场景任务成功率（沙箱终态确定性断言，EvaluateAll）。
- 检验：McNemar 精确二项检验（α=0.05 双侧）；判定工具注册合法性以 A6 签名验签 + 沙箱断言为前置（非法工具的「成功」判 0 并入对抗审计）。
- 次指标：生成→注册转化率、彩排/对抗淘汰率、token 成本（配对 bootstrap 95% CI，描述性）。
- 多重比较：命题 1/2 两主指标 → Holm 校正（α 分配 0.05/0.025 顺序检验）。

## 命题 2：工具复用率 ≥60%

### ⑤ 假设与口径

- H1：注册工具中跨任务复用占比 ≥60%。
- 口径：FleetReuseReport（分母 = 注册工具数，Wilson 下界口径——工程地板已实现）；复用 = 同一工具在 ≥2 个独立任务轨迹中被调用。
- 判据：**复用率点估计 ≥60% 且 WilsonLowerBound(复用工具数, 注册工具数, 1.959964) ≥0.60**。
- 样本量：注册工具数 n 使下界达标——n=30 全复用 → 下界 0.841；n=60、复用 42（70%）→ 下界 0.582 不达标、复用 45（75%）→ 0.632 达标；执行时随观测积累，达标即停（序贯观测，无功效门——描述性比例判据）。

### ⑥ token 成本估算

- 命题 1：118 次运行（59×2）× 每题预算 ≈ 数百万 token（同 v6.1 量级）。
- 命题 2：零额外 LLM 成本（复用报表从运行轨迹统计，随命题 1 跑批顺带产出）。
