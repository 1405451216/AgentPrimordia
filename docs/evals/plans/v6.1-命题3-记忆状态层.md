## ③ 主指标（两个并列门：二值化口径与判定器）

**门 A：state→persist→recall 闭环覆盖率（确定性覆盖度指标）**

- **分析单元**：基准任务（整集 24 题，逐题判定）。
- **二值化口径**：该题闭环四事件——state 建立 → persist 持久化（于跨会话中断点前）→ recall 召回（恢复后）→ consume 消费（进入后续推理）——全部发生且时序正确 = 1，否则 = 0。
- **判定器**：state-checkpoint 协议审计事件序列检查（事件存在性 + 时序，确定性检查器，随 v6.1 交付并进 CI）；叠加 internal/eval/asserts.go 的 EvaluateAssertion（asserts.go:166）对恢复后沙箱终态作确定性断言复核（断言常量 asserts.go:33-39：file_exists / file_contains / file_eq / json_path_eq / lines_match_count / tool_registered / tool_output_json_eq）。判定不依赖 LLM。
- **门值**：24/24 全过 = 覆盖 100%；缺任一题即未达标（确定性门无 partial、无放宽）。

**门 B：旧文本路径一致性（抽样比率）**

- **分析单元**：记忆读写对账段 = 一次记忆写入事件 + 其后续全部同键读取事件。
- **二值化口径**：对照侧与处理侧该段记忆路径输出结构化等值 = 1，否则 = 0；等值语义同 asserts.go json_path_eq 的 parseExpectedJSONValue / jsonValuesEqual 结构级比较（asserts.go:288/370）——确定性等值，非语义相似度，无 LLM。
- **门值**：点估计 ≥99%（n=300 抽样，见 ⑤/⑥）。

- **禁 LLM judge**：两门均无 LLM 成分；judge 仅存于 S0-1 judge 标定集用途，与本命题无关（asserts.go:9-11）。

## ⑤ 样本量与判定精度（无 SampleSizeMcNemar 适用性的声明）

- **不适用声明**：本命题无双臂成功率主门，不调用 SampleSizeMcNemar；功效速查表的 McNemar 行仅适用于命题 1。
- **门 A（穷尽而非抽样）**：题面集冻结有限（24 题），覆盖判定为确定性事件检查，可穷尽测试——无统计功效概念；24/24 即覆盖 100%。
- **允许 100% 的依据（R3 预登记）**：确定性逻辑不变式由代码保证可穷尽测试——V7 路线图 §一 R3 条款原文（「确定性逻辑不变式……允许 100%/0，因其由代码保证可测试穷尽」）+ 模板统计口径表第 4 行（确定性不变式——含覆盖度——允许 100%/0）+ 路线图 §三命题 3 对该指标的确定性覆盖度定性。门 B 是抽样比率，不享此例外。
- **门 B 样本量（本计划书预登记）**：n=300 段（路线图未定 n，验收只认注册口径）。依据：n=300 时 99% 门等价于「失败 ≤3 段」——失败恰 3 段时点估计 99.0%、Wilson 95% 区间 [97.1%, 99.7%]；n 更小则单条失败即破 99%，门过脆；对账为离线确定性计算，零增量 LLM token。
- **扩样纪律**：不得以扩样（n>300）重算救门——扩样属抽样协议变更，须维护者书面批准并登记后按新协议全量重跑。
- **双门互斥造假空间**：门 A 穷尽覆盖与门 B 抽样一致性互为牵制——覆盖率虚高不推出一致，二者同验（提案 §四风险表「双指标互斥造假空间」口径）。
- **多重比较**：两门并列、各自独立判定（路线图命题 3 原文即双门并列，无 p 值检验），无族内校正；次指标不做门槛。

## ⑦ 成本估算

- **token 量级**：覆盖度 24 次 × 180 calls × 1.2k tok/call ≈ 5.2×10⁶ token；一致性 48 次 ≈ 1.0×10⁷ token；合计 ≤1.6×10⁷ token（独立跑口径；复用轨迹口径 ≤1.0×10⁷ token）。
- **预算级别**：里程碑级（24/24 穷尽 + n=300 抽样为本计划书注册的验收口径；探索级 ≤20 题 × 1 采样不可用于验收）。
- **预算通道**：V7 路线图 §九 B4；金额按申请时点旗舰价目填列并对照告警线，超支触发铁律 8 裁剪评审，禁止静默缩水样本。

## ⑨ 判定口径（R3）

- **门 A 达成**：24/24 全过。报告写法：「24/24（确定性覆盖度指标——R3 允许 100% 的唯一例外，依据：确定性逻辑不变式由代码保证可穷尽测试）」。缺任一题即未达标，确定性门无 partial、无放宽。
- **门 B 达成**：点估计 ≥99%（n=300 等价式：失败 ≤3 段）；报告 = 点估计 + Wilson 95% 区间成对披露（internal/eval/stats.go WilsonInterval，stats.go:65）。预登记参考值示例：297/300 → [97.1%, 99.7%]；**若 300/300 → 「300/300，Wilson 95% 区间 [98.7%, 100%]」——禁裸 100% 宣称**（门 B 是抽样比率，不属确定性例外）。
- **报告物清单**：覆盖度逐题事件表（24 行）+ 一致性 300 段对账原始记录 + 运行五元组台账，随报告归档可复核；整集口径与留出子集口径同时披露，禁止以子集重算替代全量口径。
- **复核方式**：两门判定均为确定性计算，第三方可按冻结题面（027b5c56）与本计划书协议独立复跑复现——复现一致是报告可验收的一部分。
- **与命题 1/2 的关系**：本命题验证状态层闭环与旧路径不回归，不替代命题 1 的 A/B 数字与命题 2 的断言准确率；三命题数字各自独立报告。
- **未达成处置**：失败题 / 失败段全量披露 + 根因修复复审 + 按原口径重跑全集；不放宽门、不静默改题面；未达标即按 ⑧ 登记降级豁免，工程地板（state-checkpoint 协议 + 审计事件 + 闭环覆盖检查器进 CI）照常交付。
