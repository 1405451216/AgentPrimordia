# AgentPrimordia v6.0.1 — 补丁版（Patch）

> **发布日期**: 2026-08-31
> **影响范围**: v6.0.0 发布后的巡检修复与工程卫生；无 API 变更、无行为破坏
> **向后兼容**: ✅ 完全兼容 v6.0.0（补丁级，仅修复与工具链改进）

## 摘要

本次为 V6 弧线收官后的首个补丁版，核心动机：**`ap init` / `ap plugin create` 生成的项目在 v6.0.0 下独立编译必挂**（workspace 模式掩盖了 pgvector replace 不传递问题）——该用户阻断修复已在 main，本版将其交付给发布通道用户。

## 修复（Fixed）

| 项 | 说明 |
|----|------|
| 脚手架编译断裂 | `buildGoMod` 统一策略：向上探测框架模块 emit 相对路径 replace + pgvector require；模板 `go 1.23`→`go 1.26`、SIV 合法占位版本；`gomod_template_test.go` 锁定行为 |
| 多轮对话记忆失效 | 回读会话历史注入 LLM 请求（`internal/agent`） |
| 评估器 OR 语义 | `requires` 片段内 `\|` 支持（Go + TS 双线） |
| 契约基线恒漂移 | `make api-extract` 补 `-no-timestamp`，`TestAPIContractNoDrift` 恢复确定性可复现 |

## 新增（Added）

- bench 与集成测试支持自定义 OpenAI 兼容端点（为 nightly 接自建/兼容端点铺路——V7 弧线 S0-1 的前置能力）

## 工程卫生（Chores）

- 全仓 gofmt（161 文件，Go 1.26 doc-comment 规则）、golangci-lint 归零（3 处 unused 清理）
- go mod tidy 对齐 5 模块；AGENTS.md 依赖边界条款同步（grpc pkg re-export / wazero 双 wasm 位置）

## 版本统一

| 组件 | 版本 |
|------|------|
| Go SDK / TS SDK / CLI / Helm | **v6.0.1**（四方一致，`version-sync-check` 门验证） |
| api-contract.json | 6.0.1 再生成（39 模块，无符号变更） |
| Python / Rust 客户端 | 无变更（独立版本线 v2.0.0） |

## 升级

`go get agentprimordia@v6.0.1` / `npm i @agentprimordia/sdk@6.0.1`——无迁移动作；v6.0.0 用户建议直升（脚手架修复）。
