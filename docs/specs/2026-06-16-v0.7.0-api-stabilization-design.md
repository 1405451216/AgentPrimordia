# v0.7.0 API 稳定化设计：分组 Functional Options + 能力不可变

> **日期**: 2026-06-16
> **状态**: Approved
> **版本**: v0.7.0
> **前置阻塞项**: 无
> **后续阻塞**: v0.8.0（包结构重构）、v1.0.0（ReActConfig 字段 panic）

## 1. 背景与动机

### 1.1 当前问题

`ReActConfig` 结构体有 14 个字段标记 `Deprecated`，计划 v1.0.0 时 panic if non-nil、v2.0.0 移除。当前 API 处于剧烈变动期：

- 用户在构造时直接设置 Deprecated 字段（如 `Toolkit`、`Memory`、`Hooks` 等）
- `NewAgent()` 已是推荐入口，但 `AgentOption` 只有 3 个标量函数
- 能力注入必须通过链式 API（`WithMemory()`、`WithRAG()` 等），无法在构造时一次完成
- 14 处代码（1 处内部 + 13 处示例/模板）仍直接使用 Deprecated 字段

### 1.2 设计目标

1. **构造时一次完成**：所有能力通过 Option 在构造时注入，无需链式
2. **14+ 参数可读性**：通过分组 struct 压缩认知负担（参考 gRPC `KeepaliveParams`）
3. **不可变核心**：构造后 `AgentConfig` 不可变，并发安全
4. **向后兼容**：现有链式 API 保留为别名，`NewReActAgent` 仍可用
5. **集中校验**：`cfg.Validate()` 一次性检查依赖关系

### 1.3 业界参考

| 框架/项目 | 模式 | 启示 |
|-----------|------|------|
| gRPC | 分组 Functional Options（`KeepaliveParams` struct + `WithKeepaliveParams()` Option） | 14+ 参数时分组 struct 比 14 个 Option 更可读 |
| controller-runtime | Manager + SetupWithManager 注册 | "构造 Manager + 注册能力 + 启动"三段式 |
| LangChain | 构造时一次性注入，运行时不可变 | 核心能力不可变，测试友好 |
| AutoGen | Register 装饰器动态注入 | 工具可动态扩展（AP 已有 Registry 支持） |

## 2. 架构设计

### 2.1 核心配置 struct

```go
// internal/agent/config.go

// AgentConfig 是 Agent 的完整配置，构造后不可变。
// 用户不直接构造此 struct，而是通过 Option 函数填充。
type AgentConfig struct {
    // ===== 核心必填 =====
    Name          string
    SystemPrompt  string
    Model         llm.Provider
    PromptTemplate *PromptTemplate

    // ===== 标量配置 =====
    MaxTurns    int
    Temperature float64
    SessionID   string

    // ===== 分组能力配置 =====
    Memory        MemoryConfig
    RAG           RAGConfig
    Observability ObservabilityConfig
    Resilience    ResilienceConfig
    Tools         ToolsConfig

    // ===== 运行时辅助 =====
    Lifecycle *Lifecycle
    Logger    *slog.Logger
}
```

### 2.2 分组能力 struct


### 2.4 构造函数

```go
// NewAgent 创建 Agent，构造后核心能力不可变。
// 这是从 v0.7.0 起的推荐入口。
func NewAgent(name, systemPrompt string, model llm.Provider, opts ...Option) (*CapabilityAgent, error) {
    cfg := defaultConfig()
    cfg.Name = name
    cfg.SystemPrompt = systemPrompt
    cfg.Model = model
    for _, opt := range opts {
        opt(&cfg)
    }
    if err := cfg.Validate(); err != nil {
        return nil, fmt.Errorf("invalid agent config: %w", err)
    }
    return buildAgent(cfg)
}

// Validate 集中校验配置
func (c *AgentConfig) Validate() error {
    if c.Name == "" {
        return ErrNameRequired
    }
    if c.Model == nil {
        return ErrModelRequired
    }
    if c.MaxTurns <= 0 {
        return fmt.Errorf("MaxTurns must be positive, got %d", c.MaxTurns)
    }
    // RAG 配置校验
    if c.RAG.Enabled && c.RAG.Store == nil {
        return fmt.Errorf("RAG enabled but Store is nil")
    }
    return nil
}

// buildAgent 从配置构建 Agent（内部函数）
func buildAgent(cfg AgentConfig) (*CapabilityAgent, error) {
    // 构造 ReActAgent（复用现有逻辑）
    reactCfg := ReActConfig{
        Name:           cfg.Name,
        SystemPrompt:   cfg.SystemPrompt,
        PromptTemplate: cfg.PromptTemplate,
        Model:          cfg.Model,
        MaxTurns:       cfg.MaxTurns,
        Temperature:    cfg.Temperature,
        SessionID:      cfg.SessionID,
        Lifecycle:      cfg.Lifecycle,
        Logger:         cfg.Logger,
    }
    a := NewReActAgent(reactCfg)

    // 注入能力（通过现有链式 API，保持双写兼容）
    cap := a.AsCapability()
    if cfg.Memory.Store != nil {
        cap = cap.WithMemory(cfg.Memory.Store)
    }
    if cfg.Memory.Summarizer != nil {
        cap = cap.WithSummarizer(cfg.Memory.Summarizer)
    }
    if len(cfg.Memory.FileScope) > 0 {
        cap = cap.WithFileScope(cfg.Memory.FileScope)
    }
    if cfg.Tools.Registry != nil {
        cap = cap.WithToolkit(cfg.Tools.Registry)
    }
    if cfg.Observability.Hooks != nil {
        cap = cap.WithHooks(cfg.Observability.Hooks)
    }
    if cfg.Observability.Tracer != nil {
        cap = cap.WithTracer(cfg.Observability.Tracer)
    }
    if cfg.Observability.Metrics != nil {
        cap = cap.WithMetrics(cfg.Observability.Metrics)
    }
    if cfg.Observability.Events != nil {
        cap = cap.WithEvents(cfg.Observability.Events)
    }
    if cfg.Observability.CostTracker != nil {
        cap = cap.WithCostTracker(cfg.Observability.CostTracker)
    }
    if cfg.Resilience.CheckpointStore != nil {
        cap = cap.WithCheckpointStore(cfg.Resilience.CheckpointStore)
    }
    if cfg.Resilience.HITL != nil {
        cap = cap.WithHITL(*cfg.Resilience.HITL)
    }
    if cfg.Resilience.Cache != nil {
        cap = cap.WithCache(cfg.Resilience.Cache)
    }
    if cfg.Resilience.ContextWindow != nil {
        cap = cap.WithContextWindow(cfg.Resilience.ContextWindow)
    }
    // RAG 特殊处理（RAGConfig 是值类型，用 Enabled 字段判断）
    if cfg.RAG.Enabled {
        cap = cap.WithRAG(cfg.RAG)
    }

    return cap, nil
}
```

### 2.6 与现有 API 的关系

```
v0.7.0（本设计）:
    NewAgent(name, prompt, model, opts...)  ← 推荐，返回 (*CapabilityAgent, error)
    NewReActAgent(cfg ReActConfig)          ← 仍可用，内部转换为 AgentConfig
    链式 API（WithMemory 等）              ← 仍可用，作为 Option 的语法糖

v0.8.0:
    NewReActAgent 标记 Deprecated
    ReActConfig 字段标记 Deprecated（编译期 warning）

v1.0.0:
    ReActConfig 字段 panic if non-nil

v2.0.0:
    移除 ReActConfig，NewReActAgent 改为内部函数
```

## 3. 用户使用示例

### 3.1 简单用法

```go
agent, err := agent.NewAgent("assistant", "你是助手", llm,
    agent.WithMemory(memStore),
    agent.WithToolkit(registry),
    agent.WithMaxTurns(15),
)
```

### 3.2 高级用法（分组注入）

```go
agent, err := agent.NewAgent("researcher", "你是研究员", llm,
    agent.WithMemoryConfig(agent.MemoryConfig{
        Store:      memStore,
        Summarizer: summarizer,
        FileScope:  []string{"./data"},
    }),
    agent.WithObservability(agent.ObservabilityConfig{
        Hooks:       hooks,
        Tracer:      tracer,
        Metrics:     metrics,
        Events:      eventBus,
        CostTracker: costTracker,
    }),
    agent.WithResilience(agent.ResilienceConfig{
        Cache:           cache,
        HITL:            &hitlCfg,
        CheckpointStore: cpStore,
    }),
    agent.WithMaxTurns(20),
)
```

### 3.3 从旧 API 迁移

```go
// 旧代码
agent := agent.NewReActAgent(agent.ReActConfig{
    Name: "assistant",
    Model: llm,
    Toolkit: registry,
    Memory: memStore,
    Hooks: hooks,
    MaxTurns: 15,
})

// 新代码
agent, err := agent.NewAgent("assistant", "", llm,
    agent.WithToolkit(registry),
    agent.WithMemory(memStore),
    agent.WithHooks(hooks),
    agent.WithMaxTurns(15),
)
```

## 6. 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| NewAgent 返回值从 `*CapabilityAgent` 变为 `(*CapabilityAgent, error)` | 现有 `NewAgent` 已返回 `*CapabilityAgent`（无 error），这是破坏性变更。但现有 `NewAgent` 只有 3 个 Option，使用量少，影响小。在 CHANGELOG 中明确标注。 |
| 链式 API 与 Option 功能重复 | 链式 API 内部改为调用 Option，保持单一实现。文档明确推荐 Option 为主、链式为辅。 |
| AgentConfig 字段过多 | 通过分组 struct 压缩，顶层只有 10 个字段（4 核心必填 + 3 标量 + 5 分组） |
