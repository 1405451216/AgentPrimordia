# 实验成本与功效模板（S0-6）

> **定位**：V7 弧线新规 R2（功效先行）的执行模板。任何验收实验（A/B、消融、标定）开工前按本模板写计划书；验收只认计划书注册过的分析口径。

## 计划书模板（每题一份，放 `docs/evals/plans/<题集>-<版本>.md`）

```
# 实验计划书：<命题一句话>
- 版本 / 命题编号：v6.1 命题 1
- 题面引用：docs/evals/long-horizon-v1.json @commit <hash>，留出子集 = holdout:true 的任务
- 双臂：A（基线）= ReAct 默认策略；B（处理）= WithWorldModel
- 主指标：任务成功率（rubric 判定，二值）；次指标：token 成本、轮数
- 效应量假设：+15pp（来自 S0-2 基线摸底实测 0/12 起测点 + 保守增量）
- 功效计算：α=0.05（双侧）、power=0.80、配对设计（同题双臂，McNemar 精确检验）
  → 期望不一致率估计 30% → **n=108 题**（SampleSizeMcNemar 精确枚举，见速查表；
  旧稿估的 71 题被功效计算证伪：71 题实际功效仅 0.581，达不到 0.80）。
  长程留出仅 9 题 → 不足部分按整集重复采样补足（采样协议不变）
- 多重比较：双臂单主指标，无校正；次指标仅描述性报告不做门槛
- 采样协议：每题双臂各 1 次采样（temperature=0 确定性解码）；非确定性 Provider 记运行 seed
- 成本估算：n×2 臂 × 平均 180 calls × 1.2k tok/call ≈ 4.7×10⁷ token（旗舰价目）≈ <金额>，走 B4 预算
- 停止规则：实验中途不得换题面/换指标；失败走降级豁免记进度表
- 判定：主指标 p<0.05 且点估计 ≥ +15pp → 命题达成；否则记工程地板交付
```

## 统计口径规范（配 `internal/eval/stats.go`）

| 场景 | 检验 | 备注 |
|------|------|------|
| 同题双臂成功率 | McNemar 精确二项检验 | 配对设计样本量远小于两独立比例检验 |
| 双臂均值类（成本/token） | 配对 bootstrap 95% CI | 不假设正态 |
| 比率类指标（复用率/拦截率/准确率） | Wilson 95% 下界 | **禁裸 100% 宣称**（R3）；`x/n，Wilson 下界` 成对报告 |
| 确定性不变式（签名/CAS/预算强制/覆盖度） | 全量通过 | 允许 100%/0——代码保证可穷尽测试 |
| 独立臂大效应（+20pp 级） | 两比例 z 检验 + 功效表 | 仅在无法配对时使用 |

### 功效速查表（α=0.05，power=0.80，双侧）

数字全部来自 `internal/eval/stats.go`（SampleSizeMcNemar / SampleSizeTwoProportion，
精确枚举 + 参考值测试锁定），不是正则近似估的——R2 要求样本量「算出来」而非「拍出来」。

| 设计 | 效应量 | 每组 n |
|------|--------|--------|
| 独立两比例（p₀=0.5） | +15pp | 170 |
| 独立两比例（p₀=0.5） | +20pp | 93 |
| 独立两比例（p₀=0.5） | +30pp | 39 |
| 配对 McNemar（不一致率 30%） | +15pp 观测 | **108 题** |
| 配对 McNemar（不一致率 30%） | +20pp 观测 | 59 题 |
| 配对 McNemar（不一致率 40%） | +20pp 观测 | 80 题 |
| 配对 McNemar（不一致率 40%） | +30pp 观测 | 34 题 |

> **R2 自纠记录（2026-08-31）**：本表旧版写「McNemar 30% 不一致率 +15pp ≈71 题」，
> 是正则近似拍的。S0-1 实现精确功效计算后实测：n=71 功效仅 **0.581**；达到 0.80 需
> **n=108**。教训入台账：验收样本量一律以 `SampleSizeMcNemar` 输出为准，禁止手估。

> 结论：**能配对必配对**——同题双臂把样本需求砍半以上，这是研究弧线 token 预算可行性的第一杠杆。

## 预算分级

| 级别 | 用途 | 规模 | 效力 |
|------|------|------|------|
| 探索级 | 开发期调参/冒烟 | ≤20 题 × 1 采样 | 不可用于验收（计划书须声明） |
| 里程碑级 | 版本验收 | 计划书注册的功效 n | 唯一合法验收口径 |
| 回归级 | nightly 例行 | 留出集全量 × 1 | 趋势监控与残余风险对账 |

## 成本模型（弧线级粗算，计划书细算）

- 主实验预估：v6.1 A/B ~3M tok × 双臂重复余量；v6.2 影子评测 3 域 × ~5k 轨迹；v6.3 缺口集 50×2 臂；v6.4 主动臂 14 天长活 + A/B；v6.5 联邦对照。**量级：弧线合计数十亿 token（v6.2 蒸馏模型接管部分回归评测后边际递减）**。
- 每条计划书必须含金额估算并对照 A1/A2/B4 预算告警线；超支即触发铁律 8 裁剪评审而非静默缩水样本。
